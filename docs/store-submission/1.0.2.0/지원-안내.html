파일 정리, 한 단계씩.

예시 파일로 먼저 연습하고, 오른쪽의 새 이름을 확인한 뒤 적용하세요.

→
2. 변경 방식바꾸기 · 템플릿 · 대소문자 · 순번
→
3. 미리보기새 이름과 충돌 표시 확인
→
4. 적용필요하면 마지막 작업 되돌리기

처음 사용하는 방법

  1. Windows에서 File Renamer를 실행합니다.
  2. 파일 추가로 시험용 파일을 선택합니다. 파일이나 폴더를 앱 안으로 끌어 놓아도 됩니다. 폴더를 넣으면 바로 아래 파일만 추가되며 하위 폴더는 재귀적으로 읽지 않습니다.
  3. 찾아 바꾸기에서 찾을 글자에 초안, 바꿀 글자에 완료를 입력합니다.
  4. 오른쪽의 현재 이름과 새 이름을 비교합니다. ‘이름 중복’이나 오류 표시가 있으면 입력을 고칩니다.
  5. 오른쪽 아래 이름 바꾸기 버튼을 누릅니다. 탐색기에서도 이름이 바뀌었는지 확인합니다.
  6. 바로 전 작업을 취소하려면 앱을 닫기 전에 되돌리기를 누릅니다. 되돌리기는 영구 백업이나 여러 단계 이력이 아닙니다.

기능별 참고

템플릿

{날짜}_{파일명}은 오늘 날짜와 원래 파일명을 조합합니다. 회사명·이름 변수는 설정에서 입력한 값을 사용합니다. 확장자는 별도로 보존되므로 템플릿에 다시 넣지 마세요.

순번

기본 이름 업무문서, 시작 번호 1, 자릿수 3, 구분자 _를 선택하면 업무문서_001부터 번호를 붙입니다. 목록 순서를 확인하세요.

문제가 생겼을 때

적용 버튼을 누를 수 없어요.

실제로 바뀌는 파일이 있는지, 이름 중복이나 사용할 수 없는 문자가 없는지 확인하세요. 충돌이 있으면 먼저 규칙을 수정합니다.

파일 이름을 바꾸지 못했어요.

오류에 표시된 파일을 다른 프로그램이 사용 중인지, 해당 폴더에 쓰기 권한이 있는지 확인하세요. 일부 실패가 나면 성공한 파일과 실패한 파일을 구분해 확인하세요. 관리자 실행을 기본 해결책으로 사용하지 마세요.

되돌리기가 안 돼요.

되돌리기는 현재 실행 중 마지막 이름 변경 작업에 한정됩니다. 앱을 닫았거나 외부에서 파일을 이동·수정했다면 복원이 불가능하거나 일부 실패할 수 있습니다. 중요한 파일은 별도 복사본으로 작업하세요.

개인정보가 전송되나요?

현재 앱은 선택한 파일명·경로와 설정을 PC에서 처리하며 개발자 서버로 전송하는 기능이 없습니다. 저장하는 설정 및 문의 이메일 처리는 개인정보 안내에 설명되어 있습니다.
