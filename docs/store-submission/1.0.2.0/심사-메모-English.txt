File Renamer_Dohi is a WPF desktop utility for batch-renaming user-selected local files. No sign-in is required.

Test steps: launch the app, add disposable sample files, select Find and Replace, enter text present in the filenames and a replacement, review the preview, and apply. Verify the filenames in File Explorer. Undo restores the last rename operation within the current app session. Template, case conversion and sequence modes are also available. File extensions are preserved.

The runFullTrust capability is used to run the desktop process for local file renaming, collision checks and undo. The application manifest specifies asInvoker. The app does not require administrator elevation for normal use.
