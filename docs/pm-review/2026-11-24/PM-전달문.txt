제목: [조치 요청] File Renamer 1.0.2.0 — Store 제출 전 DPI 경고 및 선택 검사 FAIL 검토

File Renamer의 Store 제출 전 검사에서 총 24개 중 22개가 통과했고, 필수 DPI 항목 WARNING 1개와 선택 ‘차단된 실행 파일’ 항목 FAIL 1개가 남아 있습니다.

DPI는 설치 경로에서 분석이 실패하지만 동일 EXE의 일반 경로 분석과 실제 창의 PerMonitorV2 동작은 정상으로 확인되었습니다. 세부 원인과 화면 배율별 실사용 검증은 아직 남아 있습니다. 선택 FAIL은 .NET/WPF 등의 참조가 검출된 것으로, 실제 외부 실행 의존성 여부를 구분해 확인해야 합니다.

첨부 보고서 기준으로 개발·QA 담당자를 지정하고, DPI 재현 조사 → 배율·기능 검증 → 필요한 수정 → 최종 후보 WACK 재검사를 진행해 주세요. 기존 임시 테스트 인증서가 만료되어 재검사에 앞서 테스트 서명 환경도 준비해야 합니다.

실제 결함은 수정 후 제출하고, 도구 경고만 남는 경우에는 근거·미실시 범위·반려 가능성을 검토한 뒤 PM이 조건부 제출 여부를 결정하는 방향을 제안합니다. 현재 결과를 완전 통과 또는 Store 심사 탈락으로 표현하지 않도록 부탁드립니다.

요청 결과물은 재현표, QA 결과, 검출 항목 분석표, 최종 WACK 원본 보고서, 수정/잔여 위험 설명 및 제출 판단입니다. 우선 1차 조사 결과와 예상 일정을 회신해 주세요.
