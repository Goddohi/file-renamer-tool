# 파일 이름 일괄 변경 (File Renamer)

Windows용 파일 이름 일괄 변경 데스크톱 앱 (C# / WPF / .NET 8). 설치 없이 실행되는 단일 exe로 배포할 수 있습니다.

## 사용법

1. 탐색기에서 파일(또는 폴더)을 창에 끌어다 놓거나 **파일 추가** 버튼으로 목록에 추가합니다.
   폴더를 놓으면 바로 아래의 파일만 추가되며 하위 폴더는 무시됩니다. 같은 경로는 한 번만 추가됩니다.
2. 아래 탭에서 **모드 하나**를 고르고 규칙을 입력합니다. 목록의 `새 이름` 열에 결과가 즉시 미리보기로 표시됩니다.
3. 충돌이 없으면 **적용**을 눌러 이름을 바꿉니다. 잘못 바꿨다면 **되돌리기**로 마지막 실행을 되돌릴 수 있습니다(1회분).

확장자는 모든 모드에서 변경되지 않으며, 마지막 `.` 앞의 이름 부분만 변환됩니다.

### 모드

| 모드 | 설명 | 예시 |
|------|------|------|
| 찾아 바꾸기 | 찾을 글자를 바꿀 글자로 치환(비우면 삭제). "정규식 사용" 시 .NET Regex | `보고서(최종)` : `(최종)` → `` ⇒ `보고서` |
| 템플릿 | `{날짜}` `{회사명}` `{이름}` `{파일명}` 변수 사용. 알 수 없는 변수는 오류 | `{날짜}_{회사명}_{파일명}_{이름}` ⇒ `20261022_오르카_견적서_최경태.xlsx` |
| 대소문자 | 전체 소문자 / 전체 대문자 / 첫 글자만 대문자 / 단어마다 첫 글자 대문자(구분: 공백, `_`, `-`) | `my REPORT_final.PDF` ⇒ `My report_final.PDF` |
| 순번 | 기본 이름 + 시작 번호 + 자릿수 + 구분자. 목록 순서대로 번호를 매김 | `보고서`, 1, 3자리, `_` ⇒ `보고서_001.pdf` |

순번은 목록에 보이는 순서대로 매겨지며, 행을 끌어서 옮기거나 **위 / 아래** 버튼으로 순서를 바꿀 수 있습니다.

### 안전장치

- 새 이름이 목록 내 다른 결과와 같거나, 같은 폴더의 기존 파일과 같거나(대소문자 무시), 금지 문자(`\ / : * ? " < > |`)가 있거나 비어 있으면 해당 행이 빨갛게 표시되고 **적용**이 비활성화됩니다.
- 이름이 바뀌지 않는 파일은 건너뜁니다.
- 파일끼리 이름을 맞바꾸는 경우도 임시 이름을 거쳐 안전하게 처리됩니다.
- 일부 파일이 실패해도 나머지는 계속 처리하고, 끝난 뒤 실패 목록(파일명 + 사유)을 보여줍니다.

### 설정

**설정** 버튼에서 날짜 형식(.NET 형식 문자열), 회사명, 이름을 편집합니다.
설정과 마지막 입력값은 `%AppData%\FileRenamer\settings.json`에 저장되어 다시 실행할 때 복원됩니다.

## 빌드 / 테스트 / 배포

```
dotnet build FileRenamer.sln
dotnet test
dotnet publish src/FileRenamer.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

배포 결과는 `publish/FileRenamer.App.exe` 입니다.

## 구조

```
src/FileRenamer.Core/          이름 계산, 충돌 검사, 실행/되돌리기, 설정 저장 (UI 의존 없음)
src/FileRenamer.App/           WPF UI
tests/FileRenamer.Core.Tests/  xUnit 단위 테스트
```
